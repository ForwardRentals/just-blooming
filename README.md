# Just Blooming

Site for Just Blooming by Cellular Gardener, an analogue PEMF practice in Squamish, BC.

- `just-blooming.html` is the source (also published as the Claude artifact preview).
- Run `python3 build.py` to regenerate `index.html`, then commit and push. Push to `main` = live on GitHub Pages.
